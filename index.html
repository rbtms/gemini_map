About this graph

This visualization maps Gemini capsules as nodes and the links between them as edges. Each circle is a capsule. Bigger circles represent larger capsules, and thicker links represent stronger connection counts. The strength of their color represent the number of different hostnames they are connected to.

Capsules with available hostnames appear in shades of blue.
Those that return an error are shown in red, and redirects are shown in orange. By default, the last two are hidden for performance. Finally, capsules with subdomains can be double-clicked for detail.

Use the controls on the side to filter by language, category, and subcategory. Click on a node to focus on it, hover on a node or edge for details, and use the search box to jump to a specific hostname. Controls only apply to nodes in the current view.

You can see more details about it on this blog article.
